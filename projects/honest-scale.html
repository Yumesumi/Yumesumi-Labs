The problem

包装越多，
价格越难比较。

在零食店、超市里，同一件商品常常有好多层包装：一箱几盒、一提几袋、大瓶还是小瓶、克重还是毫升。标签上的总价根本没法直接比较。

Honest Scale 做的是一件很小的事——剥掉包装的迷惑，把任何东西都折算到同一把尺子下的单位价格，让你在三秒钟内知道到底哪个更划算。

“每个人买东西时，心里都有一杆称量「值不值」的秤。诚实地衡量，明明白白地买。”
名字由来 · 心里那杆秤

What it does

把一件小事，算清楚

没有复杂设置，填入价格与规格，单位价就会自己出现。

  • 01

    液体换算

    ml / L 自动换算到「元 / ml」，不用自己按计算器。

  • 02

    固体换算

    g / kg 自动换算到「元 / g」，重量与体积分开比较。

  • 03

    多层包装

    每件规格 × 每包件数 × 购买包数，「一箱几盒」也能算清。

  • 04

    并排比价

    任意数量商品同屏比较，自动标出每组最划算的一个。

  • 05

    精确计算

    基于 BigDecimal 换算，不让浮点误差改变最终结论。

  • 06

    细节体验

    Material 3、深色模式、状态自动保存，也支持高刷新率屏幕。

Example

同一把尺子，重新看价格

以牛奶为例：箱装看起来更便宜，按单位价算却未必。

A · 箱装

某品牌牛奶（箱装）

250 ml / 盒 · 12 盒

¥48总价

0.016元 / ml

总量 3000 ml

VS

B · 单卖

同规格牛奶（单卖）

500 ml / 盒 · 1 盒

¥6总价

0.012元 / ml

总量 500 ml 最划算

看起来箱装更便宜，换算成单位价后，单盒 500 ml 的其实更划算——这就是心里那杆秤存在的意义。

Design notes

诚实，是计算的前提。

重量与体积不能凭空互换。没有密度信息，就不做跨维度比较。

界面按重量、体积分两组，各自给出「最划算」的结论；不为了方便，给出不诚实的答案。

Changelog

最近的版本

从 1.0.0 到 1.0.3，一边用，一边磨。

1.0.3当前版本

  • 修复比价结论卡被手势导航栏遮挡的问题，底部留白适配系统导航。

1.0.2

  • 滚动性能优化：收敛重组范围，输入与滚动不再带动全部卡片重绘。
  • 比价结论卡固定在底部，商品再多也不用滚到列表末尾。
  • 商品显示编号；退出应用后重新打开，自动恢复上一次的清单与结果，顶栏支持一键重置。
  • 正式版开启 R8 代码收缩与资源压缩，安装包从 24 MB debug 降至约 5 MB release。

1.0.1

  • 适配 120Hz / 144Hz 高刷新率屏幕。
  • 全新自适应应用图标：森林绿底与天平简笔，支持 Android 13 主题图标。

1.0.0

  • Jetpack Compose + Material 3 全面重构。
  • 任意数量商品动态增删与同屏横向比价，自动标记最划算的一项。
  • 最低支持 Android 10（API 29），输入状态在旋转与进程重建后不丢失。
